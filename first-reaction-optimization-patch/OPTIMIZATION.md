# Остановка события после первой реакции

## Что изменено

- `stepping_action.cpp`: после обнаружения пары вторичных частиц `proton + triton` в `He3Gas` вызывается `G4RunManager::GetRunManager()->AbortEvent()`. Останавливается только текущее событие, не весь запуск.
- `event_action.h/.cpp`: `MarkReaction()` теперь возвращает `true` только при первом срабатывании в событии и увеличивает `DetectedEvents` ровно один раз.
- `run_action.h/.cpp`: оставлен только счётчик `DetectedEvents`. Знаменатель — `G4Run::GetNumberOfEventToBeProcessed()`, то есть число событий, переданное в `BeamOn()`.
- `run_scan.C`: ROOT-дерево сохраняет `TotalEvents` и `DetectedEvents`.
- `plot_efficiency.C`: эффективность рассчитывается как `DetectedEvents / TotalEvents`, а биномиальная ошибка — с тем же `TotalEvents`.

## Почему AbortEvent, а не AbortRun

`AbortEvent()` помечает текущий `G4Event` как прерванный и очищает оставшиеся треки этого события. Цикл обработки `BeamOn(N)` продолжает переходить к следующим событиям. `AbortRun()` здесь был бы ошибкой: он прекратил бы весь запуск.

Geant4 завершает event processing и учитывает событие в `G4Run`; досрочно прекращается транспорт треков внутри этого события. Счётчик `DetectedEvents` увеличивается до вызова `AbortEvent()`, поэтому факт регистрации реакции не теряется.

## Применение

Распаковать архив поверх корня текущего проекта. Архив намеренно не содержит `main.cpp`, `settings.h`, `compile.sh` и пользовательский файл распада Cf-252: они не нужны для этой оптимизации и не должны быть перезаписаны.

После замены файлов:

```bash
./compile.sh
./main 1 10
```

Для ROOT-сканирования сначала пересоздать дерево:

```bash
root -l -q 'run_scan.C()'
root -l -q 'plot_efficiency.C()'
```

Старый `simulation_results.root`, содержащий ветвь `BornNeutrons`, несовместим с новой схемой дерева. `run_scan.C` создаёт ROOT-файл заново с `RECREATE`.

## Проверка

В этой среде проверены согласованность имён методов и ROOT-ветвей, отсутствие оставшихся ссылок на удалённые счётчики `BornNeutrons`/`DetectedReactions`, а также синтаксис `compile.sh`. Сборка и физический прогон требуют локально установленных Geant4, ROOT и FREYA.
