# Neutron-detector-efficiency: Geant4 + FREYA

Полная рабочая папка проекта. Все исходные файлы, необходимые для сборки, находятся непосредственно в этой директории; старые архивы, резервные копии исходников и готовые исполняемые файлы не вложены.

## Где переключается режим распада

Откройте **`settings.h` в корне этой папки**. Внутри пространства имён `Settings` находится настройка:

```cpp
inline constexpr GenerationMode GENERATION_MODE = GenerationMode::FREYA;
```

Допустимые значения:

```cpp
GenerationMode::GEANT   // ядро Cf-252 создаёт Geant4, распад разыгрывает RadioactiveDecay
GenerationMode::FREYA   // продукты одного спонтанного деления Cf-252 генерирует FREYA
```

Чтобы переключить режим, измените только значение `GEANT`/`FREYA` в этой строке. После изменения пересоберите программу.

## Что остаётся общим

`PrimaryGeneratorAction::GeneratePrimaries()` по-прежнему выбирает `Settings::N_IONS` случайных точек в объёме образца. Распределение координат источника не зависит от выбранного режима. В каждой выбранной точке вызывается один из двух механизмов розыгрыша:

- `Geant4DecayGenerator::GenerateCf252(...)` — создаёт неподвижное ядро Cf-252, дальнейший распад выполняет Geant4;
- `FreyaFissionGenerator::GenerateCf252()` — генерирует один акт спонтанного деления и возвращает `FreyaFissionResult`.

`PrimaryGeneratorAction` преобразует результат FREYA в первичные нейтроны и гамма-кванты Geant4 и добавляет их в то же `G4Event`. Отдельного `FreyaOutputWriter` нет.

## Требования

- Geant4 с доступной командой `geant4-config`;
- ROOT с доступной командой `root-config`;
- FREYA 2.0.5: `fissionEvent.h` и `libFission`;
- GCC с поддержкой C++17.

По умолчанию сборочный скрипт ожидает FREYA в `$HOME/llnl/fission_v2.0.5`. Другой путь можно задать через `FREYA_ROOT`.

## Сборка

Из этой директории:

```bash
./compile.sh
```

Если FREYA установлена в другом каталоге:

```bash
FREYA_ROOT=/полный/путь/к/fission_v2.0.5 ./compile.sh
```

Скрипт создаёт исполняемый файл `main` в этой же директории.

## Запуск

```bash
./main
./main 20 10000
```

Аргументы: толщина PE в сантиметрах и число событий Geant4. По умолчанию — 20 см и 1 событие.

## Данные FREYA

Сначала используется `FREYADATAPATH`, если переменная окружения задана. Иначе ожидается каталог:

```text
$HOME/llnl/fission_v2.0.5/data_freya
```

В нём должен присутствовать `react.dat`. Альтернативный путь:

```bash
export FREYADATAPATH=/полный/путь/к/data_freya
```

## Состав папки

- `settings.h` — настройки, в том числе переключатель GEANT/FREYA;
- `primary_generator.cpp/.h` — общий выбор координат и маршрутизация к нужному генератору;
- `geant4_decay_generator.cpp/.h` — прежний путь распада средствами Geant4;
- `freya_fission_generator.cpp/.h` — вызов FREYA и извлечение продуктов деления;
- `freya_fission_result.h` — структура данных одного акта деления;
- `main.cpp`, `detector.*`, `he3_electric_field.*` — запуск и модель детектора;
- `run_action.*`, `event_action.*`, `stepping_action.*` — статистика и обработка событий;
- `plot_efficiency.C`, `run_scan.C`, `style_efficiency.C` — ROOT-макросы анализа;
- `assets/` — изображения из исходного проекта;
- `reference_results/` — прежние результаты, приложенные только для справки, не результаты FREYA.

Подробная карта изменений и связи между компонентами находится в `ИЗМЕНЕНИЯ.md`.

## Ограничения проверки

Эта папка собрана из предоставленного архива проекта и включает FREYA-интеграцию. Сборка и моделирование должны быть проверены в локальной среде, где доступны установленные Geant4, ROOT и FREYA 2.0.5. Наличие исходников в архиве само по себе не означает, что бинарная сборка уже проверена на целевой машине.
