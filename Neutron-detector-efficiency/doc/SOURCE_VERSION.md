## Пользовательская таблица распада Cf-252

`main.cpp` теперь содержит код подключения пользовательской таблицы только в
режиме GEANT. По умолчанию ожидается файл:

```text
data/z98.a252_modify.txt
```

Сам файл данных в архив не включён: он не присутствовал в предоставленном
`geant.zip`. Его нужно положить в `data/` или указать путь через переменную
окружения `G4_CF252_DECAY_DATA_FILE`. Таблица должна быть проверена и задавать
для Cf-252 только канал спонтанного деления с ветвлением 100%; иначе
`TotalDecays` в режиме GEANT не будет означать число только актов SF.

Полную сборку и физический запуск в этой среде проверить нельзя: здесь нет
установленных Geant4, ROOT и FREYA 2.0.5. Выполнены только проверки доступной
структуры файлов и синтаксиса shell-скрипта.
